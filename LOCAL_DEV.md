# Local Development

This site is **Jekyll + Tailwind**. Jekyll builds the site; Tailwind compiles the CSS. They're two separate processes, so local dev needs **two terminals running at once**.

## The setup

**Terminal 1 — Jekyll (serves the site + live reload):**

```bash
bundle exec jekyll serve --livereload
```

**Terminal 2 — Tailwind (compiles CSS on every save):**

```bash
# Tailwind v3:
npx tailwindcss -i ./assets/css/main.css -o ./assets/css/output.css --watch

# Tailwind v4:
npx @tailwindcss/cli -i ./assets/css/main.css -o ./assets/css/output.css --watch
```

> Not sure which version? Check the top of `main.css`:
> `@tailwind base; ...` → **v3**.  A single `@import "tailwindcss";` → **v4**.

With both running: save `main.css` → Tailwind regenerates `output.css` → Jekyll's livereload refreshes the browser.

## Things to remember

- **Edit `assets/css/main.css`, never `assets/css/output.css`.** `main.css` is the source; `output.css` is generated by Tailwind and gets overwritten. The page links to `output.css`, but you only ever touch `main.css`.
- **Jekyll doesn't compile Tailwind.** That's why Terminal 2 exists. If Tailwind isn't running, CSS changes won't show no matter how many times you refresh.
- **`_config.yml` changes aren't watched.** Edit it → stop and restart Jekyll (Terminal 1). Everything else rebuilds automatically.

## If CSS changes aren't showing

1. Is Terminal 2 (Tailwind) actually running? Most common cause.
2. Did you edit `main.css` and not `output.css`?
3. Check that the change made it into `output.css`, then hard refresh (Cmd/Ctrl + Shift + R).
